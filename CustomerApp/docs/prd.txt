Tentu. Untuk **MVP**, saya sarankan aplikasi ini jangan dibuat seperti marketplace besar terlebih dahulu. Fokus pada **booking layanan home care → penjadwalan terapis → kunjungan → pembayaran → rating**, dengan arsitektur yang nantinya mudah dikembangkan menjadi marketplace multi-cabang/multi-terapis.

# PRD — Aplikasi Home Care & Wellness

### Web Responsive + PWA

**Nama sementara:** `CareHome`
**Platform:** Web App + PWA
**Target:** Mobile-first, responsive desktop
**Model:** Customer melakukan booking layanan ke terapis yang datang ke rumah.

---

## 1. Product Vision

Aplikasi untuk memudahkan pelanggan memesan layanan kesehatan/wellness ke rumah seperti:

* Akupunktur
* Bekam
* Pijat refleksi
* Pijat tradisional
* Massage
* Pijat relaksasi
* Terapi kebugaran
* Layanan wellness lainnya

Customer tidak perlu datang ke tempat praktik. Customer cukup:

> **Pilih layanan → pilih jadwal → masukkan alamat → pilih terapis → bayar → terapis datang ke rumah.**

# 43. Definisi "MVP Selesai"

MVP dianggap berhasil apabila:

> **Customer dapat melakukan booking layanan home care dari HP sampai pembayaran dan layanan selesai tanpa bantuan admin.**

Dan:

> **Terapis dapat menerima booking, melihat lokasi customer, mengubah status kunjungan, dan menyelesaikan layanan dari HP.**

Sementara:

> **Admin dapat mengelola layanan, terapis, booking, pembayaran dan laporan.**

Itu sudah cukup untuk **launch versi pertama**.

## Rekomendasi saya

Untuk model bisnis ini, saya akan membuatnya **bukan sekadar aplikasi booking pijat**, tetapi dari awal menggunakan konsep:

**Home Care Service Platform**

sehingga nantinya bisa berkembang:

```text
                  HOME CARE
                      │
       ┌──────────────┼──────────────┐
       │              │              │
    Wellness       Beauty        Healthcare*
       │              │              │
   ┌───┼───┐      ┌───┼───┐      ┌───┼───┐
   │   │   │      │   │   │      │   │   │
 Bekam  Pijat  Refleksi  Facial  Hair  Nails  ...
```

Dengan demikian **category + service + therapist** menjadi engine utama, bukan membuat aplikasi khusus "bekam".

Untuk tahap coding, saya paling merekomendasikan **CodeIgniter 4 + Bootstrap 5 + PostgreSQL + PWA + Leaflet + payment gateway**, karena cukup ringan untuk MVP dan mudah dikembangkan menjadi multi-cabang/multi-terapis.
